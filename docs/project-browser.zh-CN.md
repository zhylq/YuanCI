# 项目浏览与仓库详情

本轮交付的是**受权限保护的只读项目浏览**，不是 GitHub 仓库导入或完整 CI。
一个项目对应一个仓库。不要把“项目已登记”理解为已经连接 Git 平台。

## 怎么打开

1. 按 [网页配置部署教程](managed-setup.zh-CN.md) 或
   [文件配置预览教程](auth-preview.zh-CN.md) 启动独立的受保护实例。
2. 完成 GitHub 登录，点击顶部“项目”，或账号首页的“查看项目列表”。
3. 输入仓库名称/所属账号搜索。点击项目名称查看组织、平台、默认分支和运行摘要。
4. 列表每页最多 20 条，支持下一页和回到首页。搜索会重置分页；浏览器地址可以收藏，
   但其中的项目 ID/游标不能授予权限，每次访问仍由服务端校验。

当前只显示已获授权且未停用的项目。没有权限的项目不会出现在搜索结果、分页数量
或详情错误中。运行列表也不会混入其他项目或旧免登录体验模式的运行记录。

## 为什么没有项目或运行记录

新建实例通常显示“还没有可见项目”，这是正常状态：本轮没有仓库发现、导入和成员
管理页面，也不会自动插入演示数据。GitHub 登录只验证你的身份，不会自动同步仓库。

下一阶段会接入 GitHub App 安装授权、仓库发现与导入。不要手工填写外部仓库 ID、
修改数据库权限或关闭登录保护来填充页面。本轮不能触发构建、重跑或部署。

仓库状态统一说明“仓库连接待接入”；本地启用标记不代表安装授权或 Webhook 可用。
运行页当前只有摘要，不包括逐步日志或执行计划。

## 页面错误说明

- **登录已过期**：重新登录后访问。不会退回免登录查询。
- **项目不可用**：项目可能不存在、停用或当前账号无权访问；三者统一提示，避免泄露。
- **没有匹配的项目**：清除搜索重试；百分号、下划线按普通文字处理，不是通配符。
- **搜索或分页参数无效**：返回项目列表重新搜索；搜索最多 100 UTF-8 字节。
- **暂时无法读取项目数据**：检查网络并重试，不会把错误当作空列表。

页面切换、刷新失败或权限失效时会隐藏旧项目数据；切换项目不沿用上一个项目的结果。
已打开页面每 30 秒及重新聚焦时刷新，服务端每个请求都重新校验权限。撤销权限不代表
能从浏览器中追回已经显示过的内容；后续实时权限通知仍可改进。

## 更新现有受保护预览

本轮没有新增数据库迁移，仍需先按现有规范备份数据库和主密钥。若已使用 managed
部署，在仓库根目录执行以下命令重建 Server（不重复运行 key-init）：

```sh
docker compose --env-file .secrets/managed.env -p yuanci-managed -f deploy/compose.managed.yml up -d --build --wait server
```

文件配置模式使用原来的 env 文件、项目名和 `compose.auth-preview.yml`。
不要把这些配置叠加到 Quickstart，也不要使用 `down -v`。本轮开发没有替你重启
正在运行的 Quickstart；旧容器不会仅因本地代码提交就自动更新。

## 开发者接口与测试

- `GET /api/v1/projects?limit=20&q=名称&after=游标`
- `GET /api/v1/projects/{projectID}`
- `GET /api/v1/projects/{projectID}/runs?limit=20&after=游标`

只接受已认证的浏览器会话，不接受 Runner Token。API 每页上限 100，返回 `items`
和可选 `next_cursor`，没有全局总数。权限过滤先于分页，游标只是当前位置，不提供
数据库快照；数据变化后重新查询可能看到不同结果。列表按项目 ID 升序，运行按时间
和 ID 倒序。接口不返回 clone URL、密钥、执行计划或未经授权的项目名称。

真实数据库安全测试通过专用 `deploy/compose.test.yml` 执行。单独查看界面状态时：

```sh
npm --prefix web run build
node scripts/project-browser-fixture.mjs
```

打开 `http://127.0.0.1:18083/projects`。顶部黄色提示明确标注虚构数据，可切换空列表、
权限撤销、会话过期和服务故障。这是本机专用视觉测试夹具，不连接数据库，不验证
真实 OAuth，也不是登录绕过功能；不包含在 Server 镜像中。按 Ctrl+C 停止。

生产可用性、真实 GitHub 沙箱和四平台端到端验收仍未完成。
